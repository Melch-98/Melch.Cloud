# Melch.Cloud

Multi-brand DTC marketing command center for Melch Media — creative pipeline, daily P&L, and paid-media analytics for the brands we run.

**Who it’s for:** Melch Media admins/strategists and brand founders (founders are locked to their own brand).

## Local run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). You’ll need the same env vars as production (Supabase, Meta, Pipeboard, etc.) for anything beyond the shell UI.
